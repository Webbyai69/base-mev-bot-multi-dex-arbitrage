Trades run on your own machine, as close to Base's sequencer as you can get it. Qortal carries everything else: this app, the shared list of Base nodes, and the status snapshots you choose to publish.

Connect your bot

read-only · the bot's machine

Qortal Hub keeps a published app away from other programs on your computer, so your bot shows up in Qortal Hub through Dev Mode. A small bridge on the bot's machine serves this app with your bot's numbers, read-only. The bridge holds a read-only token; the app never sees one, and nothing here can trade.

  1. Start the bot. In its terminal (http://127.0.0.1:8787/terminal): AI agents → Issue token, with the read scope only.
  2. Copy qortal/bridge/bridge.env.example to bridge.env and paste the token in.
  3. Run npm run qortal:bridge and leave it running.
  4. In Qortal Hub, turn on Dev Mode in your profile, open Dev Mode apps, choose Add custom framework, and enter 127.0.0.1 with port 8790.

The bridge only answers its own machine, so Qortal Hub has to run there for live numbers. From anywhere else, watch a published snapshot instead.

What goes where

    

      
On Qortal
  • This app
  • Shared lists of public Base nodes
  • Status snapshots you choose to publish
  • The release itself

      
Never on Qortal
  • Keys, seed phrases and .env
  • Private or paid RPC addresses
  • Wallet and contract addresses
  • Trading records and learned data

      
On your machine
  • The bot and its keys
  • The node you send through
  • The bridge, bound to this machine only
